# Quire Guided Project Launch — Step 24

Step 24 adds a structured first-run path for creating a new thesis or research project.

## Why it exists

Earlier versions could create another project, but the researcher was dropped into a large Study Setup screen with little guidance.

The guided launch collects only the information needed to create a coherent starting workspace, while keeping every field editable later.

## Five-step launch

### 1. Project identity

The wizard collects:

- working thesis/project title;
- degree/programme;
- institution;
- supervisor/advisor.

Only a working title is required to create the project.

### 2. Research question and objectives

The researcher can enter:

- working research question;
- up to three initial objectives.

Objectives entered here become real first-class objective records and immediately appear in the Thesis Map.

If objectives are not yet known, they can be left blank and added later.

### 3. Study design

Choices are:

- Not decided yet;
- Qualitative;
- Quantitative;
- Mixed methods;
- Systematic review / meta-analysis.

Population and study setting/context can also be captured.

The selected study type feeds the existing adaptive Study Setup and Methodology workspaces.

### 4. Targets and timeline

The wizard collects:

- thesis word target;
- proposal deadline;
- final submission deadline.

These values immediately feed:

- milestones;
- Progress Intelligence;
- timeframe calculations;
- later completion forecasting.

### 5. Initial chapter structure

The researcher chooses a starting scaffold:

- Empirical thesis;
- Evidence synthesis;
- Compact structure.

The chapter framework is editable after project creation.

## Generic project creation

A new research project no longer receives the stoma-specific objective/theme examples that existed in the original prototype.

New projects now receive only data explicitly entered by the researcher plus the chosen chapter scaffold.

Themes begin empty so they can emerge from the actual research rather than being pre-populated with unrelated examples.

## Project launch readiness

The Thesis Overview now includes a persistent launch-readiness panel.

It checks:

- project identity;
- research question;
- study design;
- objectives;
- word target + submission date;
- chapter structure.

It also provides a next action for starting the Research Library.

The checklist is derived from real project data, so it updates as Study Setup, chapters and the research library change.

## Entry points

Guided launch opens from:

- **My Research → New research project**
- **New → New thesis project**

The existing project-edit modal remains available for editing an already-created project's basic metadata.
