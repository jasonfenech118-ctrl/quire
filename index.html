LOCAL MODE

Claim-level grounding works without a backend

Quire extracts the article page-by-page, preserves passage positions, and attaches the exact supporting passage to each claim. This mode is extractive rather than generative.

OPTIONAL GENERATIVE AI

Connect a secure server endpoint

For generative summaries and answers, connect Quire to your own HTTPS backend. The backend should hold the AI provider secret; never place a secret API key in the browser.

Quire sends only retrieved article passages with stable context IDs, plus the question, article metadata and study context. A compliant endpoint returns each generated claim with the context IDs that directly support it.
